# Continuous Improvement Workflow

Analyze the entire application.

Perform one improvement cycle:

## Review

Act as:

- Senior Angular Engineer
- UX Designer
- Performance Engineer
- Code Reviewer

Find the highest-value issue.

## Implement

Fix the issue.

Do not:
- rewrite working features
- introduce unnecessary dependencies
- reduce existing functionality

## Validate

Run:

- tests
- production build
- lint if available

## Review

Assume another senior engineer will reject this PR.

Fix anything found.

## Commit

Create a conventional commit.

Continue until the application reaches production quality.
